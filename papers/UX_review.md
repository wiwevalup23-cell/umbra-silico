# UX Scope: Umbra Silico

Дата пересмотра: 2026-07-16
Область: React/Vite приложение в `apps/app`

## Продуктовая граница

Umbra Silico — спокойное local-first приложение для личных заметок, а не
универсальный конструктор рабочих пространств. Его задача — быстро открыть,
записать, организовать и найти приватную заметку на desktop или mobile.

Приложение не должно превращаться в клон Notion. Сложность оправдана только
там, где она улучшает ежедневное письмо, навигацию и доверие к локальным данным.

## Финальный набор функций

### Основа заметок

- local-first хранение в IndexedDB или SQLite;
- optional sync через Supabase;
- создание, редактирование и debounced autosave;
- поиск по заголовку, тексту и тегам;
- папки и подпапки;
- корзина с восстановлением и окончательным удалением;
- блокировка заметки с клиентским шифрованием;
- понятные состояния сохранения и синхронизации.

### Редактор

- заголовки, списки, цитаты и базовое inline-форматирование;
- таблицы;
- task, toggle и callout блоки;
- block handle;
- перемещение, дублирование, удаление и `turn into` для блоков;
- undo/redo.

Редактор остаётся компактным. Slash menu, synced blocks, comments, embeds и
полноценный print-layout не являются обязательной частью продукта.

### Page properties

У заметки есть небольшой, явный набор свойств:

- `status`: без статуса, идея, в работе или готово;
- сохранённые теги — до 12 тегов на страницу.

Теги являются частью модели заметки, сохраняются локально, попадают в sync
snapshot и участвуют в поиске. Для locked notes свойства шифруются вместе с
содержимым.

Произвольные custom properties, formulas, relations и rollups не входят в scope.

### Templates

Поддерживается небольшой встроенный набор:

- Blank note;
- Daily note;
- Meeting notes;
- Project brief.

Шаблон задаёт стартовый документ, статус и теги. Конструктор пользовательских
шаблонов и marketplace не нужны.

### Quick switcher

`Ctrl/⌘ K` открывает компактное окно, из которого можно:

- найти и открыть заметку;
- создать пустую заметку;
- открыть template picker;
- перейти в корзину;
- открыть настройки.

Это навигационный инструмент, а не универсальная command palette.

### Mobile UX

На ширине до 820 px приложение показывает один рабочий слой за раз:

- Notes;
- Editor;
- Details.

`MobileTabBar` переключает эти слои. Desktop rails и трёхколоночная сетка на
mobile не используются; topbar сокращается до основных действий, а модальные
окна превращаются в удобные нижние панели.

## Что сознательно не строим

- database views: board, calendar, gallery и timeline;
- formulas, rollups и relation properties;
- knowledge graph, backlinks и linked mentions;
- spaces и многопользовательские workspaces;
- custom template builder;
- сложную историю версий с diff;
- AI-чат, автономную реорганизацию данных и рекомендательные workflow;
- полный аналог Notion command system.

Эти функции не считаются UX-долгом. Возвращаться к ним стоит только после
подтверждённого пользовательского спроса.

## Проверка качества

### Mobile

- [x] `MobileTabBar` подключён к реальному состоянию workspace.
- [x] Одновременно виден только один рабочий слой.
- [x] Topbar помещается на узком экране.
- [x] Editor и Details занимают доступную ширину.
- [x] Нижняя навигация учитывает safe-area.

### Properties и tags

- [x] Свойства сохраняются через Repository и local store.
- [x] Теги не извлекаются regex-эвристикой из текста.
- [x] Теги добавляются и удаляются в Inspector.
- [x] Поиск находит заметки по тегам.
- [x] Свойства locked note не сохраняются открытым текстом.

### Templates и navigation

- [x] Есть явная кнопка создания пустой заметки.
- [x] Есть отдельное аккуратное окно выбора шаблона.
- [x] Quick switcher доступен кнопкой и через `Ctrl/⌘ K`.
- [x] Quick switcher ищет заметки и содержит только основные действия.

## Критерий завершённости

После выполнения этого scope продукт считается функционально собранным.
Дальнейшая работа — исправление реальных ошибок, доступность, производительность
и визуальная полировка существующих сценариев, а не добавление новых крупных
подсистем.
