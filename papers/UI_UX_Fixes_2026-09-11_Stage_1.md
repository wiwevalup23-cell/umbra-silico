# Umbra Silico — первые исправления desktop UI/UX

Дата: **11.09.2026**. Основание: [desktop-аудит этапа 06.09.2026](UI_UX_Audit_2026-09-06_Desktop.md), завершённый 10.09.2026. База изменений — снимок `1906bc22` версии 0.0.5.

## Выбранная группа

Закрыты **D05, D06, D07, D04, D11 и D18**. В первую группу вошли ошибки поиска и названий областей, затем локальные изменения плотности и поведения панелей. Они не требуют переустройства редактора, миграции базы или общей смены визуальной системы.

Сохранены бумага, serif-типографика, Platinum, плеер и существующее семейство элементов управления. Пустые состояния и новые подписи добавлены в оба словаря, русский и английский.

## D05 · P1 · «Все заметки» и «Без папки» — закрыто

«Все заметки» теперь использует общий запрос без ограничения папкой. «Без папки» — отдельный пункт дерева и отдельное физическое назначение перемещения. Заметки внутри существующих папок не исчезают из общей подборки.

В поле поиска явно указана область: вся библиотека либо выбранная папка. Пустая папка и пустой раздел «Без папки» имеют собственные сообщения. Создание заметки из общей подборки сохраняет её без папки; создание внутри папки сохраняет выбранного родителя. Импорт получает физическое назначение, а не виртуальную подборку.

Проверено: библиотека с тремя заметками — без папки, в родителе и во вложенной папке; поиск по слову в содержимом вложенного документа; отсутствие этого документа в «Без папки»; создание из общей подборки; подписи назначения в диалоге перемещения. Регрессионный тест репозитория проверяет все три области и сохранение общего количества после перемещения.

Основные файлы: `app/App.tsx`, `viewmodel/app-ui-store.ts`, `viewmodel/folders-view-model.ts`, `ui/components/notes/FolderTree.tsx`, `NoteList.tsx`, `MoveToFolderDialog.tsx`.

## D06 · P1 · Русский поиск команд — закрыто

Поиск учитывает отображаемое название, описание и локализованные синонимы. Английские запросы сохранены. Сообщение об отсутствии результата также локализовано.

Проверено: «настройки», «оформление», «фон», «корзина», «восстановить», «шаблон», а также settings/trash/template. Каждый автоматический сценарий проверяет не только наличие результата, но и выполнение правильной команды через Enter. В браузере запрос «настройки» открыл настройки.

Основной файл: `ui/components/notes/QuickSwitcher.tsx`.

## D07 · P2 · Длинные названия папок — закрыто

Название текущей папки ограничено двумя строками. Через раскрытие в заголовке доступен полный путь, включая родителей. Раскрытие работает мышью и клавиатурой; при переходе в другую папку закрывается. Короткие заголовки общей библиотеки сохраняют полосатый декоративный элемент.

Проверено: исходное длинное имя из аудита и вложенная папка «Черновики». Закрытый заголовок занимает 46 px; весь header на границе 1279/1280 px — около 117 px. Полный путь виден после Enter на раскрытии. Шестистрочный заголовок больше не сдвигает поиск вниз сам по себе; увеличение при явном раскрытии пути остаётся намеренным.

Основные файлы: `ui/components/notes/NoteList.tsx`, `app/App.tsx`, `ui/styles/silicon-nostalgia.css`.

## D04 · P2 · Маркеры и доступ к тегам — закрыто

Инспектор показывает выбранные маркеры компактными подписями. Полный набор из 13 вариантов доступен через «Изменить маркеры». Закрытие списка сохраняет выбор; при переходе к другой заметке раскрытие сбрасывается. Убрано длинное пояснение при отсутствии тегов, оставлены поле добавления и назначенные теги.

Проверено: начальное состояние без маркеров; открытие через Enter и закрытие через Space; выбор «Важное» и «Идея / озарение»; добавление тега «Аудит»; сохранение после перезагрузки. При 1280×720 статус, два выбранных маркера и поле тегов видны одновременно. Набор из большого количества выбранных значений при необходимости использует существующую прокрутку инспектора.

Основной файл: `ui/components/notes/WorkspaceInspector.tsx`.

## D11 · P2 · Пустой и длинный заголовок заметки — закрыто

У пустого заголовка есть подсказка «Название заметки». Поле переносит текст и увеличивается до двух строк. Более длинное название доступно прокруткой внутри поля, навигацией с клавиатуры и полной подсказкой при наведении. При изменении ширины пересчитывается высота; поле имеет видимый фокус.

Сохранены автосохранение, сохранение при уходе из поля, Ctrl/⌘ S и переход к тексту по Enter. Переводы строк при вставке нормализуются в пробелы, поскольку название остаётся одним значением.

Проверено: пустая заметка; название из 101 символа на 1024 и 1280 px; переход Ctrl+End к символу 101 с прокруткой поля; сохранение и повторное открытие; 1440×900. Существующие тесты автосохранения и кнопки сохранения обновлены под textarea без ослабления проверок записи.

Основные файлы: `ui/editor/NoteEditor.tsx`, `ui/editor/NoteTitleField.tsx`.

## D18 · P2 · Возврат из режима фокуса — закрыто

Фокус временно скрывает панели, не перезаписывая обычную раскладку. После выхода возвращается прежнее сочетание. Выбор панелей хранится локально между запусками; сам временный режим фокуса после перезапуска не включается. На компактном desktop инспектор поверх редактора открывается только по явному запросу.

Проверено: все четыре сочетания раскрытых/свёрнутых панелей; повторное монтирование во время фокуса; переход с широкого окна на компактное; открытие компактного инспектора, вход/выход из фокуса; повреждённое значение настроек. В браузере подтверждены возврат состояния «библиотека открыта, инспектор закрыт» и его сохранение после reload.

Основной файл: `viewmodel/workspace-layout-view-model.ts`.

## Проверки и границы этапа

- `npm run check` — успешно.
- `npm run lint` — успешно, включая ограничения архитектуры.
- `npm run test:run` — **490 тестов в 60 файлах**, все успешно; добавлено 19 регрессионных сценариев.
- `npm run build` — успешно. Остались прежние неблокирующие предупреждения о размере чанка и смешанном импорте BackupPanel.
- Живая проверка — отдельный origin `http://127.0.0.1:5175/`, три тестовые заметки и две папки. Размеры: 1024×768, 1279×720, 1280×720, 1440×900. Ошибок в журнале страницы на момент проверки не обнаружено.
- Личная база Tauri и текущие заметки пользователя в сценариях не использовались. Изменений схемы данных нет.
- Этот этап изменяет исходники и проверенную frontend-сборку. Системный Debian-пакет на устройстве этим этапом не обновлялся.
